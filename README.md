# Lerun — редактор каруселей

Редактор каруселей для Instagram и Telegram, собранный строго по макету
Figma «💚 Great Lerun». Человек, который не умеет в дизайн, открывает его,
набирает текст — и получает слайды по гайдлайну. Испортить макет нельзя:
цвета, шрифты, кегли и поля зашиты в код и берутся только из системы.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5178`. Для сборки статики — `npm run build`,
результат в `dist/` (это обычные файлы, их можно просто положить на любой хостинг).

## Что внутри от макета

| Из Figma | Где в коде |
| --- | --- |
| Цвета (7 переменных + белый) | `src/design/tokens.ts` → `PALETTE` |
| Размерная сетка 144/80/96/80/60/44/40/32 | `src/design/tokens.ts` → `TYPE_SCALE` |
| Слайд 1080×1440, поля 160/120/180/120, контент 840×1100 | `src/design/tokens.ts` → `FORMATS` |
| 12 паттернов (вектор + стоки 16px + layer blur) | `src/design/patterns.ts` |
| Шум `style=warm` / `style=black` (noiseSize 2, density 1) | `src/design/noise.ts` |
| Компоненты text / list / Quote / photo / photo caption | `src/render/blocks.tsx`, `src/render/PhotoLayer.tsx` |
| Подпись канала (Montserrat 32/32, 50 %) | `src/render/SlideView.tsx` |

Шрифты лежат локально в `public/fonts` (Montserrat и Montserrat Alternates
с Google Fonts, Rhythmic RUS сконвертирован из `fonts-source/Rhythmic_RUS.otf`).
`npm run fonts` пересобирает `src/styles/fonts.css` и `src/fonts/embedCss.ts` —
второй нужен, чтобы PNG выгружались с зашитыми шрифтами и без интернета.

## Как это работает

**Слайд = фон + фото + паттерны + блоки контента + шум + подпись.**
Блоки лежат в безопасной зоне 840×1100 и раскладываются автолейаутом —
сверху, по центру, снизу или враспор. Блоки перетаскиваются прямо на слайде,
но только по вертикали — меняются местами, а не ставятся в произвольную точку.
Это осознанно: так слайды держат одну сетку. Границы безопасной зоны
включаются кнопкой «Сетка» на вкладке «Контент».

**Темы.** Восемь проверенных комбинаций «фон + текст + акцент + паттерн».
Одна кнопка перекрашивает слайд или всю карусель.

**Декор.** Шум всегда на всю карточку и не двигается. Паттерны таскаются
мышкой за круглую ручку, крутятся, меняют цвет, размер, мягкость и могут
уходить за текст или поверх него.

**Проверка.** Вкладка «Проверка» ловит то, что обычно портит карусель:
контент не влез в безопасную зону, текст сливается с фоном, слишком длинная
фраза для выбранного кегля, нет заголовка на первом слайде, в рукописном
шрифте нет нужного знака, больше 10 слайдов для Telegram.

**Текст → карусель.** Вставляете готовый текст поста, `---` разбивает на
слайды, строки с `1.` или `—` превращаются в список. Первый кусок становится
обложкой.

**Слайды.** Лента слева: перетаскивание мышью меняет порядок, ↑↓ переключают
слайд, `⌘D` дублирует слайд или выбранный блок. Настройки блока раскрываются
прямо под ним в списке, а стиль текста выбирается плашками с живым превью
кегля и гарнитуры.

**Фото.** Перетащите картинку на слайд, вставьте через `⌘V` или кликните
дважды по слайду. Дальше фото кадрируется прямо мышью, плюс есть масштаб и
затемнение в панели «Стиль». Четыре раскладки из макета: во весь слайд,
скруглённое (радиус 184), карточка 840×900 и три арки 333×760.

**Выгрузка.** 1080×1440 (или ×2) — JPEG для публикации (≈350 КБ на слайд) или PNG
без потерь. По одному слайду, всё разом в ZIP, копия в буфер обмена. Проект
сохраняется автоматически и выгружается в `.json`.

## Горячие клавиши

| | |
| --- | --- |
| `N` | шаблоны слайдов |
| `⌘Z` / `⇧⌘Z` | отменить / вернуть |
| `⌘E` | выгрузка |
| `⌫` | удалить выбранный блок или паттерн |
| стрелки | сдвинуть выбранный паттерн (с `⇧` — крупным шагом) |
| `⌘V` | вставить картинку из буфера на слайд |
| `⌘D` | дублировать блок или слайд |
| ←→ / ↑↓ | предыдущий / следующий слайд |
| `⌘` + колесо | зум канваса |

## Структура

```
src/
  design/    токены, паттерны, шум, темы, шаблоны слайдов
  render/    отрисовка слайда 1:1 — то же самое идёт в PNG
  ui/        интерфейс редактора
  lint/      проверки по гайдлайну
  export/    PNG / ZIP / JSON
  store/     состояние, история, автосохранение в IndexedDB
```

`src/render` — единственное место, где слайд превращается в пиксели.
Превью, миниатюры и экспорт используют один и тот же компонент, поэтому
выгрузка всегда совпадает с тем, что на экране.
